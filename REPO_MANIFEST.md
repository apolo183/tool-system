# REPO_MANIFEST.md

## Authority

This file is the repository-local formal-file registry for tool-system. It registers current tool-system authority, configuration, implementation, tests, CI, and deterministic fixtures without turning retained milestone or task process inputs into current authority.

This manifest is effective only in an accepted tool-system main commit. It does not grant authority over another repository, authorize target mutation, authorize cleanup, or authorize production deployment.

## File and Graph Semantics

- Every `Formal Files` path is one exact repository-relative tracked regular file.
- Every tracked path must belong to exactly one formal-file row or one retained non-authority set.
- `upstream` is the only source of directed formal-file dependency edges. Tokens are separated by semicolons and must name exact registered formal files.
- Exact token `ROOT` is exclusive and identifies the only local formal authority root.
- `downstream` is informational and grants no reverse authority.
- Formal files must be tracked, regular, non-empty, non-symlink files.
- Retained non-authority files are not runtime defaults, rollback authority, or current-task authority.
- The exact `Formal Files` table and retained non-authority set registration are tool-system-owned tracked-path controls.
