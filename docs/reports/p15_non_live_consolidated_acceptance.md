# P15 Consolidated Non-Live Acceptance Evidence

## Outcome

On guarded merge, every P15 requirement that can be proven without a live provider is mapped to current executable or content-addressed repository evidence. P15 remains unaccepted and the final live smoke remains unexecuted.

## Evidence consolidation

- Two isolated projects cover Python and TypeScript plus greenfield, modification, repair, deletion, topology, policy block, cancellation, no-progress, crash-resume, and conflict behavior.
- OpenAI, DeepSeek, and Qwen adapters remain covered by injected fake-I/O tests.
- Provider selection is deterministic, API-default-disabled, repository-external, one-success bounded, and returns `NO_AVAILABLE_PROVIDER` when no eligible route exists.
- Eight frozen failure/economics cases cover availability, quality repair/escalation, policy blocks, cancellation, finite attempts, no-progress, isolation, rollback planning, and synthetic integer economics.
- Safety, quality, data-transfer, authorization, budget, expiry, stale-precondition, and cancellation controls cannot be bypassed by provider switching or economics.

## Metrics

Quality counts accepted isolated projects, rejected unauthorized cases, and fake-I/O adapter coverage. Time uses bounded logical development and attempt cycles, with Hosted CI wall time treated as advisory. Economics remain integer synthetic microunits with private inputs excluded. Recovery and policy counts are explicit in the consolidated matrix.

## Final smoke packet schema

The repository contains only a non-authorizing schema. Its defaults disable API and provider execution, authorize no network, budget, credential, or data transfer, contain no credential value, allow one provider and one attempt only, and require a new explicit user authorization bound to the then-canonical main.

## Read-only remaining-item mapping

Only two acceptance decisions remain:

1. separately authorize and execute one controlled smoke through any single explicitly enabled usable provider key on the then-canonical main;
2. after reviewing that smoke and all non-live evidence, separately decide whether to accept P15.

Simultaneous provider availability, Qwen funding, and a moving alias exact version are not remaining gates. P16 entry, production, real downstream access, cleanup, and rollback execution remain unauthorized.
